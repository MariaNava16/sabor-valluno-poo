## Estructura del proyecto
- `modelo/`: Clases del sistema (`Producto`, `Pedido`, `Pago`, `Cliente`, `Restaurante`), menú de consola (`main.py`) y pruebas unitarias (`pruebas.py`).
- `docs/`: Diagramas de clases UML (`diagrama_v1.jpeg`, `diagrama_v2.jpeg`), acta de consultas y registro de uso de IA.

## Cómo ejecutar
Desde la carpeta `modelo/`:
- Ejecutar el sistema: `python main.py`
- Ejecutar las pruebas: `python pruebas.py`
